# ─────────────────────────────────────────────────────────────────────────────
# cinqflow / requirements/base.txt
#
# The runtime that ships at EVERY rung, 0.5 through 4. Organised by pin, because
# that is the only organising principle that survives a socket climb.
#
# Note what is absent: no message broker, no cache, no cloud SDK, no API gateway
# client. Those are ADR-0014's "measure first" seats, and their absence from the
# image is what makes Law 1 true by construction rather than by lint.
# ─────────────────────────────────────────────────────────────────────────────

-r core.txt
