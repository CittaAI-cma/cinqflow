# Data Analyst Workflow

## Core Workflow

A practical end-to-end data analyst workflow is:

**Business Question → Define Problem → Find Data → Understand Data → Profile Data → Clean & Prepare → Validate Data → Analyze Data → Test Hypotheses → Calculate Metrics → Segment & Compare → Identify Insights → Recommend Action → Communicate Results → Document & Automate → Business Decision**

## Analyst Mindset

The analyst continuously moves through six questions:

**Question → Understand → Trust → Analyze → Explain → Recommend → Decide**

### 1. Question
What business problem are we trying to answer?

### 2. Understand
What data exists, what does it represent, and what are the relevant entities, measures, dimensions, and time periods?

### 3. Trust
Is the data complete, consistent, accurate, timely, and fit for the intended analysis?

### 4. Analyze
What trends, relationships, segments, anomalies, differences, and patterns exist?

### 5. Explain
Why is the observed behavior happening, and what evidence supports the conclusion?

### 6. Recommend
What should the business investigate, change, prioritize, or decide?

## Implication for an AI-Powered Data Platform

The platform should support the analyst's natural flow instead of forcing them through technical data-engineering steps.

The ideal experience is:

**Business Question → AI Understands Data → Data Quality & Context → Relevant Analysis → Evidence → Insight → Recommendation → Analyst Decision**

AI should reduce the manual effort of data discovery, profiling, interpretation, anomaly identification, and explanation while keeping the analyst in control of the final decision.
